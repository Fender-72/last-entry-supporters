# Last Entry — Soutiens

Liste publique utilisée pour les badges dans la map VRChat.

## Modifier les soutiens

Ouvrir [supporters.txt](supporters.txt), cliquer sur le crayon, ajouter ou retirer les pseudos VRChat exacts (un par ligne), puis valider avec **Commit changes**. Les lignes vides et celles commençant par `#` sont ignorées. Ne pas ajouter de guillemets.

URL publique pour Unity :

https://masakiyoshi.github.io/last-entry-supporters/supporters.txt

La map consulte la liste à l'arrivée puis toutes les cinq minutes. Le déploiement GitHub Pages et ses caches peuvent ajouter un délai. Pas besoin de republier la map après une modification de la liste.

## Configuration Unity initiale

Après import des scripts, ouvrir **Tools → Last Entry → Patreon → Configurer la liste en ligne**, conserver l'URL ci-dessus et cliquer pour relier les deux UI. Sauvegarder la scène et publier la map une première fois avec ce système.

## Confidentialité et fonctionnement

Le fichier est public : ajouter les pseudos avec l'accord des personnes. Ne jamais publier de clés API, jetons Patreon, emails ou données de paiement. Cette liste est manuelle et ne vérifie pas les abonnements Patreon automatiquement. Le badge est uniquement visuel.
