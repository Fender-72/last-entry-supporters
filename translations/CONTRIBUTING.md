# Proposer une traduction

Merci de contribuer à Last Entry !

- Une pull request par langue ou petit groupe de corrections rend la relecture plus simple.
- Modifiez seulement les valeurs `translation` dans le fichier de la langue.
- Le français, les identifiants et les variables restent inchangés.
- Indiquez si vous êtes locuteur natif et expliquez les corrections de vocabulaire ou de lore qui peuvent être ambiguës.
- Les traductions sont destinées à être intégrées et distribuées avec le jeu Last Entry. Ne proposez pas de texte copié depuis une source que vous n'avez pas le droit de réutiliser.

Si vous ne souhaitez pas modifier le JSON, ouvrez une Issue avec : langue, phrase française, traduction actuelle, correction proposée, contexte ou capture.

Toutes les propositions sont relues par le créateur avant intégration. Aucun accès au projet Unity n'est requis.
